# BookLens — 전자책 실시간 단어 팝업

복사가 막힌 전자책(DRM 적용 웹 뷰어·앱)에서도 **모르는 단어 위에 마우스를 올리고 ⌥ Option 키를 누르면**, 화면을 직접 읽어 **문맥에 맞는 한국어 뜻**을 팝업으로 보여주는 macOS 메뉴 막대 앱입니다.

- 화면 인식: Apple Vision OCR (Mac 내장, 무료, 오프라인)
- 뜻 추론: Ollama 로컬 AI 모델 (기본 `qwen3:8b`, Apache 2.0 — 상업적 이용 가능)
- 외부 유료 API 없음 · 화면과 단어는 이 Mac 밖으로 나가지 않음 · 스크린샷은 디스크에 저장하지 않음
- DRM을 해제하지 않습니다. 이미 화면에 보이는 픽셀만 읽습니다.

## 빠른 시작

```bash
./build.sh          # 빌드 → 서명 → /Applications/BookLens.app 설치 → 실행
```

처음 실행하면 **설정 도우미**가 뜹니다.

1. **화면 기록 권한** → `권한 허용` → 시스템 설정에서 BookLens 켜기 → `허용 후 다시 시작`
2. **Ollama** → 이미 설치·실행 중 (`brew services start ollama`로 로그인 시 자동 실행)
3. **AI 모델** → `qwen3:8b` 이미 다운로드됨

그다음 브라우저에서 리디/킨들 웹 뷰어를 열고, 단어 위에 마우스를 둔 채 **⌥ Option**을 누르세요.

## 사용법

| 동작 | 방법 |
|---|---|
| 단어 찾기 | 단어 위에서 ⌥ Option 누르기 (⌥를 누른 채 다른 단어로 옮기면 바로 갱신) |
| 발음 듣기 | 팝업의 🔊 |
| 팝업 닫기 | 마우스를 멀리 움직이거나 아무 곳이나 클릭 |
| 단어장 | 메뉴 막대 아이콘 → 단어장 열기 (⌘L) · 검색 · 삭제(⌫) · **Anki용 CSV 내보내기** |
| 설정 | 호출 방식(⌥ / ⌃ / 키 없이 멈추기), 설명·다른 뜻 표시, 자동 저장, AI 모델 선택·다운로드, 로그인 시 실행 |

팝업 내용: 표현(구동사·숙어 자동 인식, 예: *gave up → give up*), 발음기호, 품사, **이 문장에서의 뜻**, 이유 한 줄, 다른 뜻 최대 3개.
Ollama가 꺼져 있거나 모델이 없으면 macOS 기본 사전(영영)으로 자동 대체합니다.

## 개발

```bash
swift test                                  # 단위 + OCR 통합 테스트 (36개)
swift run booklens-bench web                # WebKit으로 전자책 페이지 렌더 → 인식 정확도 측정
swift run booklens-bench web1x              # 1x 모니터 가정
swift run booklens-bench e2e qwen3:8b       # 렌더 → OCR → 문장 추출 → AI 뜻 (전 과정)
swift run booklens-bench models qwen3:8b    # 모델 품질/속도 비교
.build/debug/BookLens --pipeline page.png X Y   # 이미지 한 장으로 전체 파이프라인 실행 (JSON 출력)
.build/debug/BookLens --render-popup out/       # 팝업·창 UI를 PNG로 렌더링 (시각 점검)
```

구조:

```
Sources/BookLensCore/   OCR(TextRecognizer), 단어 위치·문장 추출(WordLocator), 검증(WordReader),
                        Ollama 스트리밍(OllamaClient/MeaningProviders), 단어장(VocabStore), 프롬프트
Sources/BookLens/       메뉴 막대 앱: 트리거(TriggerMonitor), 화면 캡처(ScreenCaptureKit), 오버레이 팝업,
                        단어장·설정·설정 도우미 창
Sources/BookLensBench/  벤치마크/E2E 도구
```

동작 흐름: ⌥ 감지 → 커서가 있는 **창의 가로 전체 × 커서 위아래 200pt** 영역을 2x로 캡처 → Vision OCR → 커서 아래 단어와 문장 추출(줄바꿈 하이픈 결합, 약어·따옴표 처리, 2단 분리) → 단어 주변만 다시 읽어 검증 → Ollama에 JSON 스키마로 요청해 스트리밍 표시 → 단어장 저장.

## 알려진 제한

- **화면 기록 권한은 사용자가 직접 허용해야 합니다.** 개발 중 이 권한이 없어서, 실제 화면 캡처 단계(ScreenCaptureKit)만은 실기기에서 직접 확인하지 못했습니다. 나머지 과정(OCR → 문장 → AI → 팝업 → 단어장)은 실제 앱 안에서 이미지 주입 방식으로 확인했습니다.
- 리디·킨들 **데스크톱 앱**은 창 캡처를 막을 수 있습니다(캡처 시 검게 나옴). 그러면 웹 뷰어를 사용하세요. 브라우저 웹 뷰어는 캡처가 가능합니다.
- macOS 15 이상에서는 화면 기록 앱에 대해 시스템이 주기적으로 권한 재확인 창을 띄울 수 있습니다.
- Esc 키로 팝업을 닫는 기능은 '손쉬운 사용' 권한이 추가로 필요해 넣지 않았습니다 (마우스 이동·클릭으로 닫힘).
- 모델을 1시간 이상 쓰지 않으면 메모리에서 내려가며, 다음 첫 조회는 약 5초 걸립니다.
- 앱은 Apple Development 인증서로 서명됩니다. 다른 Mac에 배포하려면 Developer ID 서명과 공증이 필요합니다.
