# BookLens — 전자책 실시간 단어 팝업

복사가 막힌 전자책(DRM 적용 웹 뷰어·앱)에서도 **모르는 단어 위에 마우스를 올리고 ⌥ Option 키를 누르면**, 화면을 직접 읽어 **문맥에 맞는 한국어 뜻**을 팝업으로 보여주는 macOS 메뉴 막대 앱입니다.

- 화면 인식: Apple Vision OCR (Mac 내장, 무료, 오프라인)
- 사전 뜻: macOS에 들어 있는 **뉴에이스 영한사전**에서 품사별로 바로 표시 (AI가 사전 뜻을 지어내지 않음)
- 문맥 뜻: Ollama 로컬 AI 모델 (기본 `qwen3:8b`, Apache 2.0 — 상업적 이용 가능). 사전 뜻을 참고해 이 문장에 맞는 뜻 하나를 고름
- 외부 유료 API 없음 · 화면과 단어는 이 Mac 밖으로 나가지 않음 · 스크린샷은 디스크에 저장하지 않음
- DRM을 해제하지 않습니다. 이미 화면에 보이는 픽셀만 읽습니다.

## 빠른 시작

```bash
./build.sh          # 빌드 → 서명 → /Applications/BookLens.app 설치 → 실행
```

처음 실행하면 **설정 도우미**가 뜹니다.

1. **화면 기록 권한** → `권한 허용` → 시스템 설정에서 BookLens 켜기 → `허용 후 다시 시작`
2. **Ollama** → 이미 설치·실행 중 (`brew services start ollama`로 로그인 시 자동 실행)
3. **AI 모델** → `qwen3:8b` 이미 다운로드됨

그다음 브라우저에서 리디/킨들 웹 뷰어를 열고, 단어 위에 마우스를 둔 채 **⌥ Option**을 누르세요.

## 사용법

| 동작 | 방법 |
|---|---|
| 단어 찾기 | 단어 위에서 ⌥ Option 누르기 |
| 문장 번역 | ⌥를 누른 채 마우스로 문장 위를 훑고 손 떼기 → 훑은 부분이 포함된 문장 전체를 한국어로 번역 (로컬 AI 필요) |
| 발음 듣기 | 팝업의 🔊 |
| 팝업 닫기 | 마우스를 멀리 움직이거나 아무 곳이나 클릭 |
| 단어장 | 메뉴 막대 아이콘 → 단어장 열기 (⌘L) · 검색 · 삭제(⌫) · **Anki용 CSV 내보내기** |
| 설정 | 호출 방식(⌥ / ⌃ / 키 없이 멈추기), 설명·다른 뜻 표시, 자동 저장, AI 모델 선택·다운로드, 로그인 시 실행 |
| 아이콘 숨기기 | 메뉴 막대 아이콘 → 메뉴 막대에서 아이콘 숨기기 (BookLens는 계속 동작). 다시 보이려면 Finder·Spotlight에서 BookLens를 한 번 더 실행 → 설정 창의 "메뉴 막대에 아이콘 보이기" |

팝업 내용: 표현(구동사·숙어 자동 인식, 예: *gave up → give up*), 발음기호, 품사, **이 문장에서의 뜻**, 이유 한 줄, 다른 뜻 최대 3개.
Ollama가 꺼져 있거나 모델이 없으면 macOS 기본 사전(영영)으로 자동 대체합니다.

## 측정 결과 (2026-11-17, M1 Max 32GB, macOS 27.2)

**단어 인식 정확도.** 리디/킨들 스타일 웹 페이지 5종 × 2 (세피아, 2단, 다크, 작은 글씨, 큰 글씨)를 WebKit으로 그리고, 단어 497개의 가운데를 하나씩 가리켜 그 단어가 나오는지 셉니다. 2x보다 낮은 해상도는 그만큼 작게 그린 뒤 2x로 키워, 앱이 일반 모니터를 캡처할 때와 같게 만듭니다.

| 화면 해상도 | 맞힌 단어 |
|---|---|
| 2x (Retina) | **495/497 (99.6%)** |
| 1.5x | 491/497 (98.8%) |
| 1x (일반 외장 모니터) | 496/497 (99.8%) |
| 0.75x | 496/497 (99.8%) |

**걸린 시간.** 캡처한 이미지부터 잰 값이며 화면 캡처 시간은 들어 있지 않습니다. qwen3:8b를 메모리에 올려 둔 상태에서 75번 조회했습니다.

9월 29일에 잰 값은 2x 496/496, 1x 492/496, 문맥 뜻 1.0–1.3초였습니다. 9월 29일 코드를 11월 12일에 다시 재도 494/497, 495/497이 나왔습니다(값이 달라진 이유는 확인하지 못했고, 그 사이의 macOS 업데이트를 의심합니다). 9월 29일 판은 AI의 뜻만 보여 줬고, 지금 판은 사전 뜻을 먼저 보여 준 뒤 그 뜻을 AI에게 함께 넘깁니다.

11월 17일에 고친 것: 줄 끝에 온 긴 줄표(—)를 Vision이 하이픈(-)으로 읽으면, 줄바꿈으로 잘린 단어처럼 앞뒤 단어를 붙이는 문제가 있었습니다(hopes— / however → hopeshowever, 0.75x–2x에서 반복). 줄 끝 획의 길이를 재서 줄 높이의 0.45배 이상이면 줄표로 봅니다(글꼴 20종에서 하이픈은 0.16–0.39배, 긴 줄표는 0.45–1.18배). 고정폭 글꼴은 하이픈과 줄표의 길이가 같아 구분하지 못합니다. 고치기 전 값은 494, 490, 495, 495, 481이었습니다.

## 개발

```bash
swift test                                  # 단위 + OCR 통합 테스트 (54개)
swift run booklens-bench dict fork use keeps # 영한사전에서 뽑은 품사별 뜻 확인
swift run booklens-bench web                # WebKit으로 전자책 페이지 렌더 → 인식 정확도 측정
swift run booklens-bench web1x              # 1x 모니터 가정
swift run booklens-bench webd 1.5           # 해상도를 바꿔 측정 (2 = Retina, 1 = 일반 모니터)
swift run booklens-bench e2e qwen3:8b       # 렌더 → OCR → 문장 추출 → 사전 뜻 → AI 뜻 (전 과정, 단계별 시간 출력)
swift run booklens-bench models qwen3:8b    # 모델 품질/속도 비교
.build/debug/BookLens --pipeline page.png X Y   # 이미지 한 장으로 전체 파이프라인 실행 (JSON 출력)
.build/debug/BookLens --render-popup out/       # 팝업·창 UI를 PNG로 렌더링 (시각 점검)
```

구조:

```
Sources/BookLensCore/   OCR(TextRecognizer), 단어 위치·문장 추출(WordLocator), 검증(WordReader),
                        Ollama 스트리밍(OllamaClient/MeaningProviders), 단어장(VocabStore), 프롬프트
Sources/BookLens/       메뉴 막대 앱: 트리거(TriggerMonitor), 화면 캡처(ScreenCaptureKit), 오버레이 팝업,
                        단어장·설정·설정 도우미 창
Sources/BookLensBench/  벤치마크/E2E 도구
```

동작 흐름: ⌥ 감지 → 커서가 있는 **창의 가로 전체 × 커서 위아래 200pt** 영역을 2x로 캡처 → Vision OCR → 커서 아래 단어와 문장 추출(줄바꿈 하이픈 결합, 줄 끝 줄표는 길이를 재서 하이픈과 구분, 약어·따옴표 처리, 2단 분리) → 단어 주변만 다시 읽어 검증(신뢰도가 낮으면 한국어로 다시 읽어 한글이면 건너뜀) → 영한사전에서 품사별 뜻 조회(즉시 표시) → 사전 뜻을 넣어 Ollama에 JSON 스키마(필드 길이 제한 포함)로 요청해 스트리밍 표시 → 단어장 저장.

## 알려진 제한

- **화면 기록 권한은 사용자가 직접 허용해야 합니다.** 개발 중 이 권한이 없어서, 실제 화면 캡처 단계(ScreenCaptureKit)만은 실기기에서 직접 확인하지 못했습니다. 나머지 과정(OCR → 문장 → AI → 팝업 → 단어장)은 실제 앱 안에서 이미지 주입 방식으로 확인했습니다.
- 리디·킨들 **데스크톱 앱**은 창 캡처를 막을 수 있습니다(캡처 시 검게 나옴). 그러면 웹 뷰어를 사용하세요. 브라우저 웹 뷰어는 캡처가 가능합니다.
- macOS 15 이상에서는 화면 기록 앱에 대해 시스템이 주기적으로 권한 재확인 창을 띄울 수 있습니다.
- Esc 키로 팝업을 닫는 기능은 '손쉬운 사용' 권한이 추가로 필요해 넣지 않았습니다 (마우스 이동·클릭으로 닫힘).
- 모델을 1시간 이상 쓰지 않으면 메모리에서 내려가며, 다음 첫 조회는 약 5초 걸립니다.
- 영한사전은 Dictionary Services의 비공개 함수로 읽습니다(실행 시점에 찾아 쓰며, 없으면 AI가 일반 뜻을 대신 작성). 사전 본문을 규칙으로 잘라 내므로 일부 단어는 뜻 조각이 어색할 수 있습니다.
- 앱은 Apple Development 인증서로 서명됩니다. 다른 Mac에 배포하려면 Developer ID 서명과 공증이 필요합니다.
